# EvaCAM Input Samples: Warning

These files are reference-only samples for the v2 input roles.

- They intentionally use generic placeholder names and numbers.
- They are not calibrated to any published device, process, or experiment.
- Do not use these files as modeling evidence or publication inputs.
- Prefer real, tested examples under `config/` when starting a new run.

The samples exist to show file ownership, references, field names, and accepted
unit forms.
